# 🌐 Mohit Verse

[![Status](https://img.shields.io/badge/status-🟢%20Completed-success)](https://github.com/mohit-sharma-001/MohitVerse)
[![License](https://img.shields.io/badge/license-MIT-blue)](https://github.com/mohit-sharma-001/MohitVerse/blob/main/LICENSE)

**Mohit Verse** is a personal developer portfolio website that brings together everything about me — from my tech stack and professional experience to my projects and certifications — all in one clean, responsive space.

---

## ✨ Features

- **About Me** – A brief introduction and background
- **Tech Stack** – Tools and technologies I work with
- **Experience** – Professional journey and roles
- **Projects** – Showcase of my work with links and descriptions
- **Certificates** – Verified credentials and achievements
- **Contact Me** – Easy way to get in touch

Each section lives on a dedicated page for smooth navigation and a polished user experience.

---

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| Next.js | React framework for server-side rendering & static generation |
| TypeScript | Type-safe JavaScript for robust code |
| Tailwind CSS | Utility-first CSS framework for rapid UI development |
| Node.js | JavaScript runtime for build tools and serverless functions |

## 💡 Usage

Simply navigate through the different pages using the site’s menu or links:

```bash
# If you want to run locally (optional)
git clone https://github.com/mohit-sharma-001/MohitVerse.git
cd MohitVerse
npm install
npm run dev
```

Then open `http://localhost:3000` in your browser.
